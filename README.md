# Student Management System 🎓

A modern and responsive **Student Management System** built using the Django Framework.  
This project helps manage student records efficiently with secure authentication, CRUD operations, and a clean user interface.

## 🚀 Live Demo

🌐 https://student-management-system-django-j9of.onrender.com/

## 📂 GitHub Repository

🔗 https://github.com/mukesh45m/Student_Management_system-django

# ⚙️ Installation Guide

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/mukesh45m/Student_Management_system-django.git
```

## 2️⃣ Move into Project Directory

```bash
cd Student_Management_system-django
```

## 3️⃣ Create Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Mac/Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 4️⃣ Install Requirements

```bash
pip install -r requirements.txt
```

---

## 5️⃣ Run Migrations

```bash
python manage.py migrate
```

---

## 6️⃣ Create Superuser

```bash
python manage.py createsuperuser
```

---

## 7️⃣ Start Development Server

```bash
python manage.py runserver
```

Now open:

```bash
http://127.0.0.1:8000/
```
